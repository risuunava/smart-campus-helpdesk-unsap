# Smart Campus Helpdesk UNSAP

Sistem helpdesk berbasis web untuk manajemen laporan IT di lingkungan kampus.

## 🚀 Tech Stack

* Backend: Laravel
* Frontend: Next.js
* ML Service: Python (planned)

## 📁 Struktur Project

```
backend/      # API Laravel
frontend/     # Next.js
ml-service/   # Machine Learning service
```

Project masih dalam tahap pengembangan awal.
